# Аутентификация и начальный администратор

## Принцип

Пароли не хранятся в открытом виде. Backend использует Argon2id через `pwdlib[argon2]`; авторизация возвращает короткоживущий JWT. Проверка прав выполняется в API, а не только скрытием кнопок интерфейса.

## Первое развёртывание

1. Скопировать `.env.example` в `backend/.env`.
2. Указать уникальный `PK_CONTROL_JWT_SECRET` и данные первого администратора:

```text
PK_CONTROL_JWT_SECRET=<случайная-длинная-строка>
PK_CONTROL_INITIAL_ADMIN_LOGIN=<логин>
PK_CONTROL_INITIAL_ADMIN_PASSWORD=<пароль-не-короче-12-символов>
```

3. Выполнить `alembic upgrade head` в каталоге `backend/`.
4. Один раз запустить `python -m app.scripts.bootstrap_admin`.
5. После успешного создания очистить `PK_CONTROL_INITIAL_ADMIN_PASSWORD` из `.env`.

Скрипт не запускается автоматически и не перезаписывает существующую учётную запись.

## Роли

- `Administrator` — управление пользователями, ролями и справочниками.
- `Specialist` — рабочая роль специалиста СППБиБДД.
- `Manager` — просмотр, аналитика, экспорт.
- `DepartmentResponsible` — назначенные нарушения и подтверждения (будет активировано вместе с модулем нарушений).

Полная матрица прав приведена в исходной архитектурной спецификации.
