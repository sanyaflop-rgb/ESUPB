# Бизнес-правила: базовая фиксация

- Для ПК III и внешних контуров статусы: «Устранено», «Не устранено», «Просрочено».
- «Устранено с просрочкой» фиксируется признаками `eliminated_late` и `days_overdue_at_elimination`, а не отдельным статусом.
- Для ПК II контроль сроков отсутствует; допустимы только «Устранено» и «Не устранено».
- Сроки считаются в календарных днях.
- Изменение срока допускается только Специалисту или Администратору после заявки подразделения и всегда аудируется.
- Номера документов нормализуются к форме с `/`: удаляется `№`, игнорируются пробелы/регистр, символы `-`, `–`, `_` заменяются на `/`.
- Критерий 2.1.7: `нарушения ПК II типов 1.1 и 5.10 / наряды-допуски на РПО`; если нарядов-допусков нет, результат Н/П. Н/П не входит в знаменатель среднего.

## Оценка эффективности производственного контроля

- Каждый критерий получает балл 0, 1, 2, «Н/П» (неприменим) или «нет данных»; пользователь никогда не вводит балл напрямую — только исходные данные (даты, да/нет, числа).
- Правила оценки хранятся в базе (`assessment_criteria`: формула, пороги, поля ввода), а не в коде интерфейса; интерфейс показывает факт, порог, балл и причину.
- Средний балл считается только по учитываемым критериям; «Н/П» и «нет данных» в среднее не входят. Вердикт: средний балл ≥ 1,00 — «удовлетворительно», ниже — «неудовлетворительно»; при отсутствии учитываемых критериев вердикт не рассчитывается.
- Периоды оценки: квартал (I–IV), полугодие (I–II), 9 месяцев, год. Критерий учитывается в оценке, если его собственный период не длиннее периода оценки (квартальный критерий — во всех периодах; годовой — только в годовой).
- Объект оценки: для критериев ПК II уровня — подразделение; для ПК III уровня и внешних органов — Служба ППБиБДД как единый фиксированный объект. При оценке подразделения критерии Службы дают «Н/П», и наоборот.
- Исходные данные вводятся на конкретный период оценки и объект; знаменатели смешанных критериев (2.1.2, 2.1.7, 2.2.5, 2.2.6) система берёт из журнала нарушений за тот же период.
- Доли считаются целочисленно, без плавающей точки: например, «устранено в срок» — 100% → 2, от 70% → 1, ниже → 0; пустой знаменатель → «Н/П».
- Знаменатель критериев «устранено в срок» (2.1.4, 2.2.1) — только меры с наступившими сроками; будущие сроки не занижают результат.
- Результат фиксируется вручную («Зафиксировать результат»): система пересчитывает оценку на момент фиксации и сохраняет полный срез критериев, средний балл и вердикт; повторная фиксация того же периода и объекта обновляет запись.

Полный набор правил поддерживается исходными документами из [SOURCE_DOCUMENTS.md](SOURCE_DOCUMENTS.md).
