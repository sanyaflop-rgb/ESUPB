# Шпаргалка: основные команды Git

Репозиторий ESUPB (аккаунт sanyaflop-rgb).

## Как устроено

Рабочая папка → `git add` → индекс (что войдёт в коммит) → `git commit` → история

## Каждый день

```bash
git status                  # что происходит: изменённые и новые файлы
git add файл                # подготовить файл к коммиту (git add . — все сразу)
git commit -m "что сделано" # сохранить версию с описанием
git log --oneline           # короткая история коммитов
```

## Посмотреть изменения

```bash
git diff                    # изменения в рабочей папке (ещё не подготовлены)
git diff --staged           # изменения, подготовленные к коммиту
```

## Отменить

```bash
git restore файл            # отменить правки в файле (вернуть как в последнем коммите)
git restore --staged файл   # убрать файл из подготовки (сам файл не трогать)
```

## Обмен с GitHub

```bash
git clone АДРЕС             # скачать репозиторий на компьютер
git pull                    # забрать свежие коммиты с GitHub
git push                    # отправить свои коммиты на GitHub
```

## Ветки

```bash
git branch                  # список веток
git switch имя              # переключиться на ветку
git switch -c имя           # создать ветку и переключиться
```

## Настройка (один раз на компьютере)

```bash
git config --global user.name "Имя"
git config --global user.email "почта"
```
